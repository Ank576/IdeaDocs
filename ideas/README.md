# Product Ideas

This directory contains product ideas organized by domain.

## Structure

```
ideas/
├── fintech/
├── health/
├── ecommerce/
└── [other-domains]/
```

## How to Contribute

1. Create or navigate to the appropriate domain folder
2. Add your idea file following the naming convention: `descriptive-idea-name.md`
3. Use the template from `templates/idea-template.md`
4. Submit a pull request

## Guidelines

- One idea per file
- Use clear, descriptive filenames
- Include problem statement, solution, and target market
- Add relevant references and inspiration sources
