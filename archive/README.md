# Archive

This directory contains deprecated, completed, or superseded ideas, PRDs, and documentation.

## Purpose

The archive maintains a historical record of:
- Completed projects and initiatives
- Deprecated ideas that have been decided against
- Outdated documentation and PRDs
- Deprecated technical approaches

## Structure

```
archive/
├── ideas/
│   ├── [archived-idea-name].md
│   └── [reason-for-archival].txt
├── prds/
│   ├── [product-name]/
│   └── deprecated-prd.md
└── technical-docs/
    ├── [deprecated-architecture].md
    └── [outdated-guide].md
```

## Archival Guidelines

1. Move items to archive when they are:
   - Completed and no longer active
   - Deprecated or superseded by newer versions
   - Decided against after review
   - No longer relevant to the organization

2. When archiving, include:
   - A note explaining the reason for archival
   - The date of archival
   - Reference to what replaced it (if applicable)

3. Archive folder structure mirrors the main structure for easy navigation

## Retrieving Archived Items

If an archived item needs to be revisited:
1. Review the archival notes
2. Check if a newer version exists in the main directories
3. Restore to appropriate main directory if needed
4. Update relevant documentation
