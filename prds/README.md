# Product Requirement Documents (PRDs)

This directory contains PRDs organized by product.

## Structure

```
prds/
├── [product-name]/
│   ├── v1.0-prd.md
│   ├── v2.0-prd.md
│   └── assets/
│       ├── diagrams/
│       ├── mockups/
│       └── screenshots/
└── [other-products]/
```

## How to Contribute

1. Create a new folder: `prds/[product-name]/`
2. Use the template from `templates/prd-template.md`
3. Follow semantic versioning: `v1.0-prd.md`, `v2.0-prd.md`, etc.
4. Store supporting assets in `assets/` subfolder
5. Submit a pull request

## Guidelines

- Use the COSTAR framework for structure
- Include clear objectives and success metrics
- Document dependencies and risks
- Keep versions organized with clear changelogs
- Include supporting diagrams and mockups in assets folder
